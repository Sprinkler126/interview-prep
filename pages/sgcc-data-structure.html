1. 逻辑结构、存储结构与抽象数据类型

对应大纲条目 1

思想 · 大白话

先想数据之间是什么关系，再想在机器里怎么摆。座位表描述同桌关系，实际座位才是存储方式。

要掌握的规则

  • 逻辑结构分集合、线性、树形、图形；存储结构常见顺序、链式、索引、散列。逻辑相邻不保证物理相邻。
  • ADT 由数据对象、关系和允许操作定义，不限定某种语言或存储实现。
  • 算法有有穷性、确定性、可行性、输入和输出；算法需有限步骤结束。
手算例子：

线性表可用顺序表或链表实现。栈是操作受限的线性表，可用数组也可用链表。

易错点：把顺序表当成逻辑结构，或把线性结构理解为内存连续。

2. 顺序表与链表

对应大纲条目 2

思想 · 大白话

顺序表像连续的编号储物柜，按号访问快；链表像寻宝纸条，插入只改连线，但找位置得逐个走。

要掌握的规则

  • 顺序表按位访问 O(1)，未排序时按值查找 O(n)，中间插删 O(n)。
  • 长度 n 的顺序表，在第 i 个位置插入（1≤i≤n+1）移动 n-i+1 项；删除第 i 项移动 n-i 项。
  • 单链表带头节点时首个数据节点为 head.next；头节点不是头元素。已知前驱时插删 O(1)，找前驱可能 O(n)。
  • 双向链表删除已知真实节点 O(1)；循环链表的末节点指回头部，遍历终止条件不能再用 null。

伪代码 / 操作步骤

insertAfter(p,x):
  node=new Node(x)
  node.next=p.next
  p.next=node
deleteAfter(p):
  if p.next==null: 报错
  victim=p.next; p.next=victim.next; 释放 victim
手算例子：

[2,4,6,8,10] 在第 2 个位置插入 3，移动 4 项；删除原表第 2 项，移动 3 项。

易错点：必须先接新节点与原后继，再改前驱指针；否则会丢失后半段。

3. 栈、表达式求值与递归

对应大纲条目 3

思想 · 大白话

叠盘子后放先取。表达式计算时，用栈临时存着还没用完的数；递归则把没做完的调用存起来。

要掌握的规则

  • 顺序栈令 top=-1 为空；入栈先 ++top 再写入，出栈先取 A[top] 再 --top；容量 m 时满栈 top=m-1。
  • 合法出栈序列必须能通过实际入栈出栈产生；n 个不同元素的合法出栈序列数为 Catalan 数 C(2n,n)/(n+1)。
  • 后缀表达式遇数入栈，遇双目运算符先弹右操作数，再弹左操作数。
  • 递归栈空间取决于最大调用深度，不等于总调用次数。

伪代码 / 操作步骤

for token in 后缀表达式:
  if token 是数: push(token)
  else:
    right=pop(); left=pop()
    push(left token right)
return pop()  // 合法表达式最终恰剩一项
手算例子：

(3+4)×2 的后缀为 3 4 + 2 ×，结果 14。按 1,2,3 入栈不能以 3,1,2 出栈，因为 2 挡在 1 上面。

易错点：减法、除法先弹出的数在右侧，不可颠倒。

4. 循环队列与双端队列

对应大纲条目 3

思想 · 大白话

队伍走到数组尽头就绕回起点。front 指向下一项出队位置，rear 指向下一次写入位置。

要掌握的规则

  • 本页统一采用牺牲一个空槽：数组容量 m，最多存 m-1 项。
  • 判空 front==rear；判满 (rear+1)%m==front；长度 (rear-front+m)%m。
  • 入队先写 A[rear] 再 rear=(rear+1)%m；出队先取 A[front] 再移动 front。
  • 双端队列两端均可入队出队；输入受限、输出受限要看题目具体限制哪一端。

伪代码 / 操作步骤

enqueue(x):
  if (rear+1)%m==front: 报错“队满”
  A[rear]=x; rear=(rear+1)%m
dequeue():
  if front==rear: 报错“队空”
  x=A[front]; front=(front+1)%m; return x
手算例子：

m=6，front=4,rear=1，长度 (1-4+6)%6=3，占槽 4、5、0。

易错点：用 size 或标志位区分满空的实现可存 m 项；先读约定，不能一律减 1。

5. 数组地址与矩阵压缩存储

对应大纲条目 4

思想 · 大白话

找座位先数跨过几整行，再加这一行内的偏移。对称矩阵像镜子两边，只存一半就能还原另一半。

要掌握的规则

  • A[L1..U1][L2..U2] 行优先：地址=base+((i-L1)×列数+j-L2)×元素字节数。列优先时先跨列，每列含行数个元素。
  • n 阶对称矩阵下三角含主对角线共 n(n+1)/2 项；0 起始 i≥j 时偏移 k=i(i+1)/2+j，i<j 时先交换。
  • 三角矩阵另一半均为同一常数时，通常额外存一个常数，共 n(n+1)/2+1 项。
  • 三对角矩阵非零项满足 |i-j|≤1，n≥2 时有 3n-2 项；稀疏矩阵可存 (行,列,值) 三元组。

伪代码 / 操作步骤

address(i,j)=base+((i-L1)*columns+j-L2)*bytes
symIndex(i,j):  // 0 起始，下三角按行
  if i<j: swap(i,j)
  return i*(i+1)/2+j
手算例子：

A[0..2][0..3] 行优先，base=100，每项 4 字节：A[2][1] 地址为 100+(2×4+1)×4=136。4 阶对称矩阵共存 10 项，A[3][1] 的 k=7。

易错点：下标从 1 开始需减下界；偏移 7 是第 8 个单元，偏移还不是字节地址。

6. 字符串：朴素匹配与 KMP

对应大纲条目 4

思想 · 大白话

匹配失败时，不必把之前的信息全丢掉。KMP 记住已匹配部分结尾能接回哪个开头，让模式串跳过不可能的对齐。

要掌握的规则

  • 朴素匹配最坏 O(nm)；KMP 建前缀表 O(m)、匹配 O(n)，总 O(n+m)。
  • 本页 pi 为 0 起始前缀函数：pi[i] 是 P[0..i] 最长公共真前后缀的长度，真前缀不能等于整段。
  • 失配时 j=pi[j-1]，文本 i 不回退，可能多次回退 j。
  • 教材 next、nextval 可能使用 -1、0 或 1 起始；必须按定义推导，不要混用表值。

伪代码 / 操作步骤

pi[0]=0
for i=1..m-1:
  j=pi[i-1]
  while j>0 and P[i]!=P[j]: j=pi[j-1]
  if P[i]==P[j]: j++
  pi[i]=j
j=0
for i=0..n-1:
  while j>0 and T[i]!=P[j]: j=pi[j-1]
  if T[i]==P[j]: j++
  if j==m: 输出 i-m+1; j=pi[j-1]
// 非空模式串；输出全部匹配，含重叠
手算例子：

P=ababaca，pi=[0,0,1,2,3,0,1]；已匹配 ababa 后在 P[5] 失配，j 从 5 回退到 pi[4]=3。

易错点：不存在不声明定义就通用的 next 数组答案。

7. 树的计数性质与完全二叉树

对应大纲条目 5

思想 · 大白话

非根节点各自只有一个父亲，数父子连线就能推出很多公式。完全二叉树则像从上到下、从左到右不留空位地坐人。

要掌握的规则

  • n 节点非空树有 n-1 条边；二叉树度为 0、1、2 的节点数 n0,n1,n2 满足 n0=n2+1。
  • 根为第 1 层，第 i 层最多 2^(i-1) 项，高度 h 最多 2^h-1 项；n 项完全二叉树高度 floor(log2 n)+1。
  • 完全二叉树除末层外均满，末层从左到右连续；满二叉树按国内常用定义每层都满。
  • 完全二叉树 1 起始编号：父 floor(i/2)、左 2i、右 2i+1；叶数 ceil(n/2)，度为 2 的节点数 floor((n-1)/2)。
  • 树转二叉树使用左孩子右兄弟：左指针连第一个孩子，右指针连下一个兄弟。

伪代码 / 操作步骤

parent(i)=floor(i/2)  // i>1
left(i)=2*i if 2*i<=n else 不存在
right(i)=2*i+1 if 2*i+1<=n else 不存在
手算例子：

n=10 的完全二叉树高度 4、叶数 5，节点 5 只有左孩子。任意二叉树若 n2=7，则 n0=8。

易错点：完全二叉树可以有一个度为 1 的节点，不能等同“每个内部节点都有两个孩子”。

8. 遍历还原与线索二叉树

对应大纲条目 5

思想 · 大白话

前序先点根，中序把根夹在左右之间，后序最后点根。知道根是谁，就能用中序把左右两堆分开。

要掌握的规则

  • 前序根左右、中序左根右、后序左右根；层序使用队列按层访问。
  • 节点值互异，前序+中序或后序+中序能唯一还原；前序+后序一般不能。
  • 二叉链表有 2n 个孩子指针、n-1 个非空指针，空指针 n+1 个。
  • 中序线索树把空左指针指向中序前驱、空右指针指向后继，tag 区分线索与孩子。

伪代码 / 操作步骤

build(pre,in):  // 节点值互异，切片示意
  if pre 为空: return null
  root=pre[0]; k=root 在 in 中的下标
  root.left=build(pre[1..k],in[0..k-1])
  root.right=build(pre[k+1..],in[k+1..])
  return root
手算例子：

前序 ABDEC，中序 DBEAC：根 A；左子树根 B，左右为 D、E；右子树 C。后序 DEBCA。

易错点：不能沿着线索继续当孩子递归，否则可能循环访问。

9. 哈夫曼树、WPL 与前缀编码

对应大纲条目 5

思想 · 大白话

常用的数据配短编码。每次把最轻的两棵树合并，最常用的数据一般能更靠近根。

要掌握的规则

  • 每轮取最小两个权重，合并的和重新参加选择；小顶堆实现 O(n log n)。
  • WPL=Σ(叶权×根到叶的边数)，也等于所有合并产生的新权重之和。
  • n≥2 个叶子的哈夫曼树有 n-1 个内部节点，总 2n-1 个节点，无度为 1 的节点。
  • 叶子路径给出前缀编码，任一码字都不是另一码字的前缀；编码本身可能不唯一。

伪代码 / 操作步骤

heap=用全部叶子建小顶堆
while size(heap)>1:
  a=popMin(); b=popMin()
  push(Node(a.weight+b.weight,a,b))
return popMin()
手算例子：

2,3,7,9：2+3=5，5+7=12，9+12=21，WPL=38；核对 2×3+3×3+7×2+9×1=38。

易错点：根权重 21 不是 WPL；左右互换会改变码字，但不改变 WPL。

10. 图的存储、遍历与连通性

对应大纲条目 6

思想 · 大白话

城市是节点，道路是边。邻接矩阵列出每对城市有没有路；邻接表列出每个城市能直接去哪里。

要掌握的规则

  • 简单无向图最多 V(V-1)/2 条边；简单无自环有向图最多 V(V-1) 条弧。无向度之和=2E，有向入度和=出度和=E。
  • 无向连通图至少 V-1 条边；边数 V-1 且连通才一定是树。强连通要求有向图任意两点互相可达。
  • 矩阵空间 O(V²)、判邻接 O(1)；邻接表空间 O(V+E)，无向边一般存两份。
  • DFS/BFS 邻接表时间 O(V+E)，矩阵实现 O(V²)；非连通图需从每个未访问点重新启动。

伪代码 / 操作步骤

BFS(s):
  seen.add(s); enqueue(s)
  while queue 非空:
    u=dequeue(); visit(u)
    for v in adj[u]:
      if v not in seen: seen.add(v); enqueue(v)
DFS(u):
  seen.add(u); visit(u)
  for v in adj[u]:
    if v not in seen: DFS(v)
手算例子：

6 个顶点简单无向图最多 15 条边；各点度之和 18 则边数 9。BFS 在无权图求最少边数路径。

易错点：非连通图一次 BFS 不保证遍历全部顶点；带不同权重时 BFS 不保证最短路。

11. 最小生成树：Prim 与 Kruskal

对应大纲条目 6

思想 · 大白话

把所有站点连起来且总成本最低。Prim 从已连好的站点向外找最便宜的连接；Kruskal 从便宜道路开始挑，不能成环。

要掌握的规则

  • 针对无向连通带权图，生成树含 V-1 边；非连通图得到最小生成森林。负权边也可以。
  • Prim 的 dist 是当前树到新点的最小连接边权；矩阵实现 O(V²)。
  • Kruskal 按边权排序，并查集判环，通常 O(E log E)。
  • 边权互异能保证唯一；有重复权重不代表一定不唯一。

伪代码 / 操作步骤

sort(edges,按权重升序)
for (u,v,w) in edges:
  if find(u)!=find(v): union(u,v); 选边(u,v,w)
  if 已选 V-1 条边: break
// Prim 每轮选最小 dist 未入树点 u
// 更新 dist[v]=min(dist[v],w(u,v))，不加 dist[u]
手算例子：

AB1,BC2,AC4,CD3,BD5：选 AB、BC、CD 总权 6；AC 会形成环而跳过。

易错点：总边权最小不代表从源点到每个节点的树内路径最短。

12. 最短路径：Dijkstra、Floyd、Bellman-Ford

对应大纲条目 6

思想 · 大白话

找家到每站最短路线，和铺路总共最省钱不同。Dijkstra 确认当前最近的站，Floyd 依次试用每个站做中转。

要掌握的规则

  • Dijkstra 要求边权非负；矩阵实现 O(V²)，邻接表配二叉堆通常 O((V+E)log V)。
  • Floyd 求所有点对最短路，k 放最外层，O(V³) 时间、O(V²) 空间；可处理负边，不能给受负环影响的路径定义有限最短距离。
  • Floyd 结束若 d[i][i]<0 表示有负环。Bellman-Ford 用 V-1 轮松弛，再一轮仍可更新则有源可达负环，O(VE)。

伪代码 / 操作步骤

dist[s]=0; 其他 dist=∞
重复 V 次:
  u=未确认点中 dist 最小者
  if dist[u]==∞: break
  确认 u
  for (u,v,w): dist[v]=min(dist[v],dist[u]+w)
// Floyd
for k in vertices:
  for i in vertices:
    for j in vertices:
      若两段可达: d[i][j]=min(d[i][j],d[i][k]+d[k][j])
手算例子：

A→B4,A→C1,C→B2,B→D1,C→D5：先确定 C=1，再更新 B=3，之后 D=4。确认顺序 A,C,B,D。

易错点：Dijkstra 更新 dist[u]+w；Prim 只更新 w。不可达的无穷值不应做可能溢出的加法。

13. 拓扑排序与关键路径

对应大纲条目 6

思想 · 大白话

先修课没学完不能上后续课。拓扑排序挑没有前置依赖的任务；关键路径找一旦延误就会拖慢整体的活动链。

要掌握的规则

  • AOV 网顶点表示活动；有向图存在拓扑序当且仅当无环。Kahn 输出少于 V 点说明有环，时间 O(V+E)。
  • AOE 网边表示活动时长。最早事件时间 ve[v]=max(ve[u]+w)，按拓扑序算。
  • 以总工期初始化汇点，逆拓扑序计算 vl[u]=min(vl[v]-w)。活动最早 e=ve[u]，最晚 l=vl[v]-w，e=l 为关键活动。
  • 关键路径可能多条；缩短其中一条的活动不一定缩短整个工期。

伪代码 / 操作步骤

queue=所有入度为0的点; order=[]
while queue 非空:
  u=dequeue(); order.append(u)
  for v in adj[u]:
    indegree[v]--
    if indegree[v]==0: enqueue(v)
if length(order)<V: 报告有环
else: 按 order 算 ve，再按逆序算 vl
手算例子：

A→B3,A→C2,B→D2,C→D4：ve=[0,3,2,6]，vl=[0,4,2,6]，A→C、C→D 关键，总工期 6。

易错点：关键路径求的是依赖约束下的最长工期；不是最短路。AOE 题应明确起止事件和非负工期。

14. 查找：顺序、折半、分块与 ASL

对应大纲条目 7

思想 · 大白话

查找效率看平均问几次。有序数据能每问一次就丢掉半边；分块则先查目录，再进小块找。

要掌握的规则

  • 等概率成功顺序查找 ASL=(n+1)/2；不带哨兵的失败需比较 n 个数据元素。
  • 折半要求顺序存储且按键有序；普通链表不能直接 O(1) 访问中点。
  • 折半最坏成功比较次数 floor(log2 n)+1（n≥1）；需声明中点取整规则。
  • 分块查找块间有序、块内可无序，先查索引后块内查找。ASL=Σ(概率×比较次数)。

伪代码 / 操作步骤

lo=0; hi=n-1
while lo<=hi:
  mid=lo+floor((hi-lo)/2)
  if A[mid]==key: return mid
  if A[mid]<key: lo=mid+1
  else: hi=mid-1
return 不存在
手算例子：

[3,7,11,15,19,23,27] 查 19：比 15、23、19 共 3 次。7 项顺序成功等概率 ASL=4。

易错点：最坏与平均不同；概率不等时不能直接套均匀公式。

15. BST、AVL 与 B/B+ 树

对应大纲条目 7

思想 · 大白话

把比较过程变成分岔路，平衡树不让路过长。多路树一次看几个分界值，使需要访问的层数更少。

要掌握的规则

  • BST 中序有序，操作 O(h)；平衡时 O(log n)，退化时 O(n)。双孩子删除可用中序前驱或后继替换后再删除。
  • AVL 平衡因子=左高-右高，允许 -1,0,1；LL 右旋、RR 左旋、LR 先左后右、RL 先右后左。
  • m 阶 B 树按最大孩子数定义：至多 m 个孩子、m-1 键；非根内部节点至少 ceil(m/2) 个孩子；内部根至少 2 孩子。
  • B+ 内部只存索引，记录在叶子，叶链适合范围查询。B+ 阶数与键数关系依教材定义。

伪代码 / 操作步骤

deleteBST(node,key):
  按大小找到目标 node
  无左孩子: 用右孩子替代
  无右孩子: 用左孩子替代
  两孩子都有:
    s=右子树最小节点
    node.key=s.key; node.value=s.value
    在右子树删除 s
// AVL 更新后回溯祖先，更新高度并按失衡类型旋转
手算例子：

AVL 插入 30,10,20 出现 LR，先对 10 左旋，再对 30 右旋，根变 20。5 阶 B 树非根内部至少 3 孩子、2 键。

易错点：阶 m 不等于最小度数 t：最小度数 t 的 B 树最多 2t 个孩子、2t-1 键。

16. 散列冲突、装填因子与 ASL

对应大纲条目 7

思想 · 大白话

键算到同一个格子时，写入和查找必须使用同一套绕行规则；删除后也不能把冲突链截断。

要掌握的规则

  • 装填因子 α=n/m；开放定址需 α<1 才有空槽，链地址法 α 可大于 1。
  • 线性探测 H_i=(H(key)+i)%m；平方探测需按题目明确的增量序列计算。
  • 成功 ASL 按每个已存键实际探测次数平均；失败 ASL 按题目规定的散列起点平均。
  • 开放定址删除需做墓碑，不能直接标成从未使用；相同键更新不增加元素数。

伪代码 / 操作步骤

search(key):
  for i=0..m-1:
    p=(H(key)+i)%m
    if slot[p] 从未使用: return 不存在
    if 非墓碑 and slot[p].key==key: return p
  return 不存在
手算例子：

m=7,H(k)=k%7，插入 10,17,24 落在 3、4、5，比较次数 1、2、3，成功 ASL=2。删 17 后查 24 必须跨过墓碑。

易错点：探测到空槽也算一次访问，成功与失败查找的统计口径不能混用。

17. 内部排序：趟数、稳定性与取舍

对应大纲条目 8

思想 · 大白话

不只看最终结果，还要看每一趟保证什么：谁已经就位，哪一段只是内部有序，哪些部分还没处理。

要掌握的规则

  • 直接插入、冒泡、归并（相等先左）以及稳定计数/基数稳定；直接选择、希尔、快速、堆通常不稳定。
  • 冒泡每趟确定极值；选择每趟选剩余最小；插入维护有序前缀；快排仅保证基准就位，两侧未必有序。
  • 选择始终比较 n(n-1)/2 次；优化冒泡、直接插入最好 O(n)。希尔复杂度依赖增量序列。
  • 归并最坏 O(n log n)、辅助空间 O(n)；堆最坏 O(n log n)、空间 O(1)，自底向上建堆 O(n)。
  • 快排平均 O(n log n)、最坏 O(n²)，递归栈平均 O(log n)、最坏 O(n)。比较排序最坏下界 Ω(n log n) 不约束计数等非比较排序。
  • LSD 基数按个位到高位，每轮必须稳定；计数适合值域小，稳定实现输出数组也占空间。

伪代码 / 操作步骤

// 直接插入；其余9种伪代码和交互见原算法页
for i=1..n-1:
  key=A[i]; j=i-1
  while j>=0 and A[j]>key:
    A[j+1]=A[j]; j--
  A[j+1]=key
手算例子：

[2a,2b,1] 选择首轮后为 [1,2b,2a]，证明不稳定。[5,3,4,1] 冒泡首趟后 [3,4,1,5]。

易错点：一次运行未打乱相等项不能证明稳定；稳定性要求所有合法输入都保持。

18. 复杂度、分治、贪心、动态规划与回溯

对应大纲条目 9

思想 · 大白话

要数输入变大时重复了多少工作。能否拆成独立小问题，复用重复结果，或有把握地排除候选，决定使用哪种策略。

要掌握的规则

  • 顺序执行取主导项；嵌套循环先看依赖关系。Σ(i=1..n)i=n(n+1)/2，为 Θ(n²)。每次翻倍为 Θ(log n)。
  • T(n)=2T(n/2)+Θ(n) 为 Θ(n log n)；T(n)=T(n/2)+Θ(1) 为 Θ(log n)；T(n)=T(n-1)+Θ(n) 为 Θ(n²)。
  • 分治拆独立子问题；DP 利用重叠子问题和合适的最优子结构；贪心必须证明局部选择安全；回溯试选、递归、撤销。
  • 辅助空间包含递归栈；输入存储是否计入总空间需按题意。0/1 背包一维容量倒序，完全背包通常正序。

伪代码 / 操作步骤

dp[0..W]=0  // 非负价值0/1背包，允许不装满
for 每件物品(weight,value):
  for c=W down to weight:
    dp[c]=max(dp[c],dp[c-weight]+value)
// 倒序使每件物品至多使用一次
手算例子：

i=1;i<n;i*=2 在 n>1 时循环 ceil(log2 n) 次。递归阶乘只有 n 层调用，但辅助栈空间仍 Θ(n)。

易错点：写了 dp 数组不保证正确，状态、转移、初值、遍历顺序都必须成立。

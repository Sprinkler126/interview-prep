第一部分：技术原理

1. 系统调用、中断与运行机制

对应大纲条目 24

思想 · 大白话

应用平时在权限较小的区域运行，遇到文件、设备等受保护资源，就通过规定入口请操作系统代办。

要掌握的规则

  • 用户态不能直接执行特权指令；系统调用通常通过陷入进入内核，执行后返回用户态。
  • 外部中断来自设备、时钟等，异常由当前指令触发，如缺页、除零；教材术语可能把陷入列为异常的一类。
  • 中断处理保存必要现场；进程上下文切换还需切换进程运行环境。进入内核不一定切换进程。
  • 并发是一段时间内交替推进，并行是同一时刻真正同时执行；操作系统还有共享、虚拟、异步等特征。
手算例子：

一次 read 系统调用可从用户态进入内核后原线程继续；若读盘等待才可能阻塞并切换到其他进程。

易错点：态切换不等于进程切换，用户态也不等于某一个特定进程。

2. 进程状态、线程与调度计算

对应大纲条目 25

思想 · 大白话

进程像独立的工作场地，线程像场地里的工人。工人没材料时等待，有材料但轮不到机器时就绪。

要掌握的规则

  • 就绪→运行由调度，运行→就绪常因时间片到，运行→阻塞因等待事件，阻塞→就绪因事件完成。通常不能阻塞直接到运行。
  • 同一进程线程共享地址空间和打开文件等资源，但各有栈、寄存器上下文；进程是资源分配单位，线程是常用调度单位。
  • 周转时间=完成-到达，带权周转=周转/服务，等待时间=周转-服务（单次 CPU 作业模型）。
  • FCFS 先到先服务；SJF 选已到达最短服务；SRTF 可抢占；RR 按时间片；优先级调度需防饥饿。
手算例子：

P1 到达0服务5，P2 到达1服务2。FCFS：P1 0–5，P2 5–7，周转 5、6，平均 5.5，等待 0、4，平均 2。

易错点：SJF 非抢占和 SRTF 抢占的时间线不同；没到达的任务不能提前被选中。

3. PV 同步、死锁与银行家算法

对应大纲条目 25

思想 · 大白话

互斥像只有一把钥匙，同步像必须等上一步完成。银行家在借资源前先试算：借出去后是否仍能安排所有人依次完工。

要掌握的规则

  • P(S) 请求资源，不够则阻塞；V(S) 释放并唤醒等待者；教材可用不同计数实现，行为约束相同。
  • 有界缓冲区通常 mutex=1、empty=N、full=0。生产者先 P(empty)，再 P(mutex)；消费者先 P(full)，再 P(mutex)。
  • 死锁四必要条件：互斥、占有并等待、不可剥夺、循环等待；预防破坏条件，避免用安全性检查，检测后恢复。
  • Need=Max−Allocation；安全性算法从 Work=Available 开始，找 Need≤Work 的未完成进程，完成后 Work+=Allocation。
  • 不安全状态不等于已经死锁；死锁属于无法继续推进的状态。

伪代码 / 操作步骤

Work=Available; Finish[所有进程]=false
repeat:
  找到未完成且 Need[i]≤Work 的进程 i
  若没有: break
  Work=Work+Allocation[i]; Finish[i]=true
return 所有 Finish 都为 true  // 存在安全序列
手算例子：

一个资源类型，Available=1；P0 Allocation=1,Need=1；P1 Allocation=2,Need=2。先完成 P0，Work=2，再完成 P1，Work=4，安全序列 P0,P1。

易错点：生产者若先持有 mutex 再等待 empty，满缓冲时可能挡住消费者取走元素。

4. 分页、地址转换、TLB 与页面置换

对应大纲条目 26

思想 · 大白话

每个进程看到自己的连续地址，操作系统把它切成页，再映射到实际内存的页框。最近用过的映射还可放进 TLB 快速查。

要掌握的规则

  • 页号=⌊逻辑地址页大小⌋，偏移=逻辑地址mod页大小；物理地址=页框号×页大小+偏移。页大小 2k 时低 k 位为偏移。
  • 分页通常产生页内碎片；分段可产生外部碎片。页表存在不等于页已在内存，缺页要看有效/驻留状态。
  • 忽略重叠，TLB 查找 t、内存访问 m、命中率 h：有效时间 h(t+m)+(1-h)(t+2m)，未计缺页。
  • FIFO 按进入时间，LRU 按最近访问，OPT 选未来最晚使用；FIFO 可能有 Belady 异常，LRU/OPT 具栈性质不出现该异常。
  • 工作集过大可能频繁换页而抖动，应考虑驻留集和多道程序度，不能只凭 CPU 利用率低就继续加进程。
手算例子：

页大小 1 KiB，逻辑地址 2500：页号2、偏移452；若页2映射框5，物理地址 5×1024+452=5572。

易错点：TLB 未命中只是没缓存到映射，不等于缺页；不能直接加一次磁盘访问。

5. 文件组织、目录与索引分配

对应大纲条目 27

思想 · 大白话

文件名像通讯录名字，目录把名字映射到文件身份。磁盘块可以连续放，也可以链接或用索引表记录。

要掌握的规则

  • 连续分配顺序和随机访问快，但扩展及外部碎片麻烦；链接分配便于扩展但随机访问弱；索引分配通过索引块找数据块。
  • 目录管理名字与文件控制信息的对应，FCB/inode 记录属性和块位置；打开文件表维护当前打开状态。
  • 块大小 B、地址项大小 a，单级索引块能放 floor(B/a) 个地址，若都指数据块则容量为该数×B。
  • 硬链接共享同一文件对象，符号链接保存目标路径；删除一个硬链接不等于立即释放仍被引用的数据。
手算例子：

4 KiB 索引块、4 B 地址，每块 1024 个地址，单级间接数据容量 1024×4 KiB=4 MiB，索引块自身另占空间。

易错点：计算最大文件时要区分数据块、索引块、直接地址项、一级和二级间接项。

6. 设备管理、磁盘调度与 DMA

对应大纲条目 28

思想 · 大白话

慢设备不该让 CPU 一直盯着。缓冲区暂存数据，设备就绪后再通知；DMA 则让控制器搬一大块数据。

要掌握的规则

  • 程序查询持续轮询，中断方式由设备通知，DMA 由控制器搬设备与内存间的数据，CPU 配置并处理完成事件。
  • 单缓冲、双缓冲可重叠部分生产和消费；SPOOLing 用磁盘队列把独占设备虚拟为可共享服务。
  • 磁盘访问常分寻道、旋转等待、传输时间；SSD 不能机械套用磁头调度收益。
  • FCFS 按请求顺序；SSTF 每次最近磁道但可能饥饿；SCAN 向一方向扫到边界再回转；LOOK 只扫到该方向最后请求。
手算例子：

磁头50，请求10、55、58：FCFS 位移40+45+3=88；SSTF 选55、58、10，位移5+3+48=56。

易错点：SCAN 与 LOOK 的边界条件不同；必须给初始方向和磁道范围才可唯一计算 SCAN。

7. 保护、安全与访问控制

对应大纲条目 29

思想 · 大白话

保护规定谁能碰哪项资源，安全还要面对恶意行为、泄露和破坏。权限应该只给完成任务必需的那一部分。

要掌握的规则

  • 访问矩阵行是主体或保护域，列是客体，单元是权限；ACL 按对象列出权限，能力表按主体列出可访问对象。
  • 身份认证确认是谁，授权决定能做什么，审计记录做过什么；三者不能替代。
  • 最小权限、用户/内核隔离、地址空间保护有助限制错误与攻击影响。
  • 口令不应明文保存，使用合适的带盐口令散列方案；普通快速哈希不能单独作为完整口令保护设计。
手算例子：

只读报表账号仅授 SELECT，不授建表、删除或管理权限；即使密码正确，也仍需逐项授权。

易错点：“登录成功”不代表有全部权限；管理员权限也不代表可以绕过审计。

第二部分：场景化讲解

FCFS 与 SRTF 对照

固定例子回放：前进、回退、重置；观察状态与每一步原因。

  1. P1 到达0、服务5；P2 到达1、服务2，假定上下文切换无开销。
  2. FCFS：P1 0–5，P2 5–7。周转5、6，平均5.5；等待0、4。
  3. SRTF：P1 0–1，此时剩4；P2 到达服务2，更短，抢占。
  4. P2 1–3 完成，P1 3–7 完成。周转 P1=7、P2=2，平均4.5；等待 P1=2、P2=0。

FIFO 与 LRU：3 个页框，1,2,3,1,4

固定例子回放：前进、回退、重置；观察状态与每一步原因。

  1. 开始空框；访问1、2、3各缺页一次。FIFO进入顺序 [1,2,3]；LRU旧→新 [1,2,3]。
  2. 再次访问1命中。FIFO顺序仍 [1,2,3]，LRU改为 [2,3,1]。
  3. 访问4缺页：FIFO淘汰最早进入的1，页框含2,3,4。
  4. LRU淘汰最久未访问的2，页框含1,3,4。二者本例均缺页4次，但淘汰对象不同。

第三部分：模拟笔试与追问

共 9 道自编单选练习，不是真题，不用于估计实际考试分值。先作答，再看推导。

1. 系统调用进入内核意味着？

答案与推导

答案：C。态切换与进程切换是两个概念。

2. 进程等待 I/O 完成后通常从阻塞变为？

答案与推导

答案：B。事件满足后可竞争 CPU，通常先进入就绪队列。

3. 到达1、完成7、服务2，周转时间？

答案与推导

答案：C。周转=7-1=6；等待=6-2=4。

4. 银行家算法的不安全状态意味着？

答案与推导

答案：B。不安全可能进一步死锁，但不等于已经死锁。

5. 页1 KiB，逻辑地址2500，页2映射框5，物理地址？

答案与推导

答案：C。页号2、偏移452，5×1024+452=5572。

6. TLB 未命中必然说明？

答案与推导

答案：B。映射可在页表，页面仍在内存；缺页需另看驻留状态。

7. 4 KiB 索引块、4 B 地址，单级间接数据容量？

答案与推导

答案：C。1024个地址×4KiB=4MiB，不把索引块当数据。

8. 磁头50，请求10,55,58，SSTF 总位移？

答案与推导

答案：B。50→55→58→10，5+3+48=56。

9. ACL 通常按什么组织权限？

答案与推导

答案：A。访问控制列表附于对象；能力表更偏主体持有哪些访问能力。

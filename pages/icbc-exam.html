一 企业文化：使命、愿景、价值观

先分清三个标签

使命

提供卓越金融服务。服务对象与责任可记为：客户、股东、员工、社会。

愿景

记忆要点：具有中国特色、世界一流现代金融企业、基业长青。完整表述见官网企业文化。

价值观

工于至诚，行以致远。五个关键词：诚信、人本、稳健、创新、卓越。

白话理解：使命回答“提供什么服务、为谁创造价值”；愿景回答“希望成为怎样的银行”；价值观回答“以什么准则做事”。

“卓越”既出现在使命中，也是价值观关键词之一。选择题要看完整表述，不能只见一个词就判断分类。

五个关键词落到行动

关键词场景化理解（学习归纳）
诚信如实说明产品特点和限制，不夸大收益、不掩盖问题。
人本理解客户和员工的实际需要，例如为老年客户提供清晰易懂的操作引导。
稳健重视风险识别和流程约束，不为了速度跳过必要审核。
创新改进服务和技术，同时做好验证、权限控制及回退准备。
卓越持续改善准确性、可靠性和服务质量。

三 战略辨析：五化不是五篇

按2025年年度报告记“五化”转型

智能化风控、现代化布局、数智化动能、综合化服务、生态化体系。

记忆顺序：先管风险，再看布局，以数据技术增强能力，整合服务，并建设协作体系。这是理解顺序，不代表官方优先级排序。

材料题怎么答：看题干指定的年份与报告。本页采用2025年年度报告口径；旧材料可能出现“数字化动能、多元化结构、生态化基础”等词，不应拼接成一套新表述。

“五化”描述工行的转型路径；金融“五篇大文章”描述重点金融领域。数字相同不代表内容相同。

五 场景理解：把文化和技术连起来

转账超时，能不能直接再扣一次

超时只说明调用方没有及时拿到结果，不能据此断言转账失败。应查询原业务结果，并通过业务单号、幂等校验和状态记录处理重试，避免重复扣款。

对应“稳健”：先确认事实，再恢复业务。技术追问可延伸到数据库事务、唯一约束、对账与异常补偿。

熟悉的客户要求跳过必要核验

说明核验的必要性，帮助客户完成所需步骤，按权限和流程处理。客户关系不能替代身份核实或必要审核。

对应“诚信、人本、稳健”：既清楚解释，也提供帮助，并守住操作边界。

新功能上线后，部分客户交易异常

先评估影响并按预案止损，保留排查证据；核实业务状态后恢复服务，复盘测试覆盖、发布策略和监控盲区。回退程序前还要考虑数据变更是否兼容。

对应“创新、卓越”：创新不只是上线功能，也包括可靠交付和持续改进。

六 自测练习

16道自编单选

先选答案再查看解析；关闭脚本时仍可展开答案阅读。

01 工行的使命对应哪项

  1. 提供卓越金融服务
  2. 发行人民币
  3. 只服务工商企业
  4. 制定全国货币政策
答案与解析

正确答案：A。使命强调金融服务；货币发行和货币政策不属于工行的商业银行定位。

02 “工于至诚，行以致远”对应哪一层

  1. 成立宗旨的年份
  2. 价值观
  3. 股票简称
  4. 客服电话
答案与解析

正确答案：B。这是工行价值观的核心表述。

03 哪组全部属于工行价值观关键词

  1. 诚信、人本、稳健、创新、卓越
  2. 诚信、激进、规模、垄断、速度
  3. 乡村、城乡、实体、普惠、养老
  4. 科技、绿色、普惠、养老、数字
答案与解析

正确答案：A。五个关键词为诚信、人本、稳健、创新、卓越。

04 工行愿景的记忆要点是哪组

  1. 只做境内业务
  2. 只追求短期规模
  3. 中国特色、世界一流、基业长青
  4. 只服务大型企业
答案与解析

正确答案：C。愿景强调长期发展目标，不是单一产品或客户范围。

05 中国工商银行成立于何时

  1. 1951年
  2. 1979年
  3. 2005年
  4. 1984年1月1日
答案与解析

正确答案：D。成立记1984年；2005年是股份制改制。

06 工行整体改制为股份有限公司的日期是

  1. 2006年10月27日
  2. 2005年10月28日
  3. 1984年1月1日
  4. 2010年7月
答案与解析

正确答案：B。股改与上市相隔约一年，不是同一天。

07 关于工行上市，哪项正确

  1. 2006年沪港同日上市
  2. 2005年仅在香港上市
  3. 1984年在上海上市
  4. 2010年沪港上市
答案与解析

正确答案：A。2006年10月27日，工行在上海和香港同日挂牌。

08 工行A股与H股代码分别是

  1. 601288与1288
  2. 601398与1398
  3. 601939与939
  4. 601988与3988
答案与解析

正确答案：B。工行记601398 / 1398，不要与农行601288 / 1288混淆。

09 工行全国电话服务热线是

  1. 95599
  2. 95533
  3. 95588
  4. 95566
答案与解析

正确答案：C。工行为95588。

10 工行属于哪类机构

  1. 中央银行
  2. 政策性银行
  3. 证券交易所
  4. 国有大型商业银行
答案与解析

正确答案：D。商业银行面向客户开展金融业务，不能与央行职能混淆。

11 按2025年报，哪项属于工行五化转型

  1. 数智化动能
  2. 任意化授信
  3. 无审核服务
  4. 单一化产品
答案与解析

正确答案：A。该报告的五化包括智能化风控、现代化布局、数智化动能、综合化服务、生态化体系。

12 旧报告与新报告的战略措辞不同，应怎样答题

  1. 任意混合成一组
  2. 总是用最早版本
  3. 按题干指定年份与材料判断
  4. 只看数字是否相同
答案与解析

正确答案：C。战略措辞需要与所引用报告一致，不能跨年拼接。

13 关于本页复习模块，哪项正确

  1. 代表所有工行岗位固定题量
  2. 是准备建议，具体以本批次通知为准
  3. 意味着计算机岗不考其他能力
  4. 是工行官方真题
答案与解析

正确答案：B。本页提供准备框架与自编练习，不承诺固定考试结构。

14 转账接口超时后，首先应注意什么

  1. 一定未扣款，直接重复执行
  2. 一定已扣款，不再处理
  3. 删除日志后重试
  4. 核实原业务状态，结合幂等机制处理
答案与解析

正确答案：D。超时不等于业务失败，盲目重试可能重复扣款。

15 熟客要求跳过必要核验，较妥当的做法是

  1. 说明要求并协助按流程完成
  2. 直接省略核验
  3. 让客户口头保证即可
  4. 隐藏操作记录
答案与解析

正确答案：A。服务便利性应与必要核验共同落实，熟悉程度不能代替审核。

16 新功能上线引发交易异常，较妥当的做法是

  1. 只重启且不记录
  2. 立即删除全部交易记录
  3. 按预案止损、核实状态并复盘
  4. 认为创新必然出错而不处理
答案与解析

正确答案：C。恢复不仅是程序恢复，还涉及交易状态、数据兼容与证据保留。

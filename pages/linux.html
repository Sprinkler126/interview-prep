1.1 文件系统

Linux 目录结构

目录用途典型内容
/bin基本命令（所有用户可用）ls, cp, mv, cat, grep
/sbin系统管理命令fdisk, iptables, reboot
/etc系统配置文件passwd, hosts, nginx.conf
/var可变数据log, spool, cache
/tmp临时文件（重启可能清除）进程临时文件
/home用户主目录/home/username
/rootroot 用户主目录
/proc虚拟文件系统（进程信息）/proc/[pid]/status, /proc/cpuinfo
/dev设备文件null, zero, sda, tty
/usr用户程序和数据bin, lib, share, local

inode 与文件权限

  • inode：存储文件元数据（大小、权限、时间戳、数据块指针），不包含文件名
  • 目录：特殊的文件，内容是 文件名 → inode号 的映射
  • 硬链接：多个文件名指向同一 inode，不能跨文件系统，不能链接目录
  • 软链接：独立 inode，内容是目标路径，可跨文件系统
# 文件权限 rwxr-xr-- (754)
# r=4(读) w=2(写) x=1(执行)
# 所有者|组|其他人

chmod 755 file        # 数字模式
chmod u+x file        # 符号模式：给所有者加执行权限
chmod -R 644 dir/     # 递归修改目录

chown user:group file # 修改所有者和组
chown -R user:group dir/

1.6 Shell 脚本

Shell 脚本基础

#!/bin/bash

# 变量
name="world"
echo "Hello, $name"
echo "参数: $0 $1 $2  参数个数: $#  所有参数: $@"

# 条件判断
if [ -f "/etc/passwd" ]; then
    echo "文件存在"
elif [ -d "/tmp" ]; then
    echo "目录存在"
else
    echo "不存在"
fi

# 数值比较用 -eq -ne -gt -lt -ge -le
# 字符串比较用 = != -z(空) -n(非空)
# 文件测试用 -f(文件) -d(目录) -r(可读) -w(可写) -x(可执行) -s(非空)

# 循环
for file in /var/log/*.log; do
    echo "Processing $file"
done

for i in {1..10}; do
    echo $i
done

while read line; do
    echo "$line"
done < file.txt

# 函数
check_port() {
    local port=$1
    if ss -tlnp | grep -q ":$port "; then
        echo "端口 $port 已被占用"
        return 1
    else
        echo "端口 $port 可用"
        return 0
    fi
}
check_port 8080

# 数组
arr=("apple" "banana" "cherry")
echo ${arr[0]}          # 第一个元素
echo ${arr[@]}          # 所有元素
echo ${#arr[@]}         # 数组长度

2.1 awk 用法

awk 基本语法

# 基本格式：awk 'pattern {action}' file
# 内置变量：$0(整行) $1-$N(字段) NR(行号) NF(字段数) FS(输入分隔符) OFS(输出分隔符)

# 打印第1和第3列
awk '{print $1, $3}' file

# 指定分隔符
awk -F: '{print $1, $3}' /etc/passwd

# 条件过滤：打印第3列大于 100 的行
awk '$3 > 100 {print $0}' file

# 模式匹配：打印包含 ERROR 的行
awk '/ERROR/ {print NR, $0}' app.log

# 统计：计算第2列的总和
awk '{sum += $2} END {print "Total:", sum}' file

# 格式化输出
awk '{printf "%-20s %10d\n", $1, $3}' file

# 多个 action（用 ; 分隔）
awk '{print NR, $0} END {print "Total lines:", NR}' file
awk 是行处理工具，逐行读入，按 pattern 匹配，执行 action。BEGIN 块在处理前执行，END 块在处理后执行。

2.2 sed 用法

sed 常用操作

# 基本格式：sed 'command' file  或  sed -i 'command' file（原地修改）

# 替换：s/old/new/flags
sed 's/old/new/' file          # 替换每行第一个
sed 's/old/new/g' file         # 替换所有（全局）
sed -i 's/old/new/g' file      # 原地修改文件
sed '3s/old/new/g' file        # 只处理第3行
sed '1,5s/old/new/g' file      # 处理第1到5行

# 删除
sed '3d' file                  # 删除第3行
sed '1,5d' file                # 删除第1到5行
sed '/pattern/d' file          # 删除匹配行

# 插入/追加
sed '3i\new line' file         # 在第3行前插入
sed '3a\new line' file         # 在第3行后追加

# 打印
sed -n '5p' file               # 只打印第5行
sed -n '1,10p' file            # 打印第1到10行
sed -n '/pattern/p' file       # 打印匹配行（类似 grep）

# 多个命令
sed -e 's/foo/bar/g' -e 's/baz/qux/g' file
sed 's/foo/bar/g; s/baz/qux/g' file

2.4 定时任务

crontab 定时任务

# crontab 语法：分 时 日 月 周 命令
# * * * * *
# | | | | |
# | | | | +-- 星期几 (0-7, 0和7都是周日)
# | | | +---- 月份 (1-12)
# | | +------ 日 (1-31)
# | +-------- 时 (0-23)
# +---------- 分 (0-59)

# 常用示例
30 2 * * * /home/user/backup.sh       # 每天凌晨 2:30
0 */2 * * * /home/user/check.sh       # 每2小时
0 9 * * 1-5 /home/user/report.sh      # 工作日 9:00
*/5 * * * * /home/user/monitor.sh      # 每5分钟
0 0 1 * * /home/user/monthly.sh       # 每月1号 0:00

# 管理
crontab -e          # 编辑定时任务
crontab -l          # 列出当前用户的定时任务
crrontab -r          # 删除所有定时任务

# 特殊字符
# * 任意值
# , 列表 (1,3,5)
# - 范围 (1-5)
# / 步长 (*/5)
crontab 中的命令要用绝对路径，因为 cron 执行时的环境变量与交互式 shell 不同。建议将命令输出重定向到日志文件。

🎤第三部分：模拟面试

Linux 中查看日志文件中包含 ERROR 的行，用什么命令？
参考：grep -n "ERROR" /var/log/app.log（-n 显示行号）。查看前后上下文用 grep -n -C 5 "ERROR" app.log（前后5行）。忽略大小写用 -i。递归搜索目录用 grep -rn "ERROR" /var/log/。
追问：实时监控日志用 tail -f app.log | grep ERROR 或 tail -f app.log。
如何查看某个端口被哪个进程占用？
参考：① ss -tlnp | grep 8080（推荐，比 netstat 快）；② lsof -i:8080；③ netstat -tlnp | grep 8080。
追问：如果要杀掉占用端口的进程：kill $(lsof -t -i:8080) 或 fuser -k 8080/tcp。
Linux 中硬链接和软链接的区别？
参考：硬链接：多个文件名指向同一个 inode，不能跨文件系统，不能链接目录，删除原文件不影响。软链接：独立的 inode，内容是目标文件路径，可以跨文件系统和链接目录，原文件删除后失效。
追问：为什么硬链接不能跨文件系统？因为 inode 号只在同一个文件系统内唯一。
如何在 Linux 中查找大文件并清理磁盘空间？
参考：① df -h 查看各分区使用率；② du -sh /var/* | sort -rh | head -10 找大目录；③ find / -type f -size +100M -exec ls -lh {} \; 查找大于 100M 的文件；④ 清理日志：find /var/log -name "*.log" -mtime +30 -delete；⑤ 清理包缓存：yum clean all 或 apt-get clean。
awk 和 sed 有什么区别？什么时候用哪个？
参考：sed：流编辑器，擅长文本替换和行操作（增删改查），逐行处理。awk：文本处理语言，擅长按字段处理和格式化输出，支持变量、条件、循环等编程特性。
选择：简单替换用 sed（sed 's/old/new/g'）；需要按字段处理或计算用 awk（awk -F: '{print $1, $3}'）。两者常配合使用。
如何用 nohup 后台运行 Java 应用？和 & 有什么区别？
参考：nohup java -jar app.jar > app.log 2>&1 &。nohup：忽略 SIGHUP 信号，终端关闭后进程不会被终止。&：将命令放入后台执行，但终端关闭时进程会收到 SIGHUP 被终止。两者结合使用：nohup 保证终端关闭后继续运行，& 保证不在前台阻塞终端。
追问：更推荐使用 systemd 管理服务（systemctl start/stop/status），比 nohup 更可靠。
Linux 中如何排查 CPU 占用过高的 Java 进程？
参考：① top 找到 CPU 占用高的 Java 进程 PID；② top -Hp <PID> 查看该进程的线程，找到 CPU 高的线程 TID；③ 将 TID 转为十六进制 printf "%x\n" <TID>；④ jstack <PID> | grep -A 30 "<TID_HEX>" 查看该线程的堆栈信息。
追问：常见原因：死循环、频繁 GC（jstat -gcutil <PID> 查看 GC 频率）、锁竞争。
crontab 中 * * * * * 分别代表什么？如何设置每5分钟执行一次？
参考：五个星号从左到右分别代表 分（0-59）、时（0-23）、日（1-31）、月（1-12）、周（0-7，0和7都是周日）。每5分钟：*/5 * * * * /path/to/script.sh。
追问：crontab 中要用绝对路径，因为 cron 的环境变量与交互式 shell 不同。建议在脚本开头 source ~/.bashrc 或在 crontab 中设置 PATH。
Linux 中如何查看系统负载？load average 多少算高？
参考：uptime 或 top 可以查看 load average（1分钟/5分钟/15分钟平均负载）。一般不超过 CPU 核心数算正常。例如 4 核 CPU，load average 持续 > 4 说明系统过载。
追问：load average 包含处于 Running 和 Uninterruptible Sleep（如等待 IO）的进程数。如果 load 高但 CPU 使用率不高，可能是 IO 瓶颈（用 iostat 确认）。

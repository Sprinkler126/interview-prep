# 面试知识复习库 (Interview Prep)

## 项目概述

这是一个用于求职面试准备的知识复习库，以HTML网页形式组织和保存各类技术知识点。

## 项目规范

### 1. 文件结构

```
interview-prep/
├── index.html          # 主菜单页/目录
├── css/
│   └── style.css       # 全局样式表
├── *.html              # 各主题子页面
└── README.md           # 项目说明
```

### 2. 内容规范

- **格式**：所有知识点必须以HTML网页形式保存
- **导航**：每个子页面必须包含返回主菜单的链接
- **结构**：每个主题一个独立HTML文件
- **命名**：文件名使用英文小写 + 连字符（如 `redis.html`, `mysql-index.html`）
- **可视化**：每个页面需包含框图/架构图/流程图等HTML图解，辅助理解

### 3. 每个主题页面的内容结构（必须遵循）

每个知识点/子页面的内容编写必须按照以下三段式结构组织：

#### 第一部分：技术原理

> 从底层原理出发，讲清楚"它是什么、怎么工作的"

- 核心概念定义
- 底层数据结构与实现原理（配框图/架构图）
- 关键机制的运作流程（配流程图）
- 重要的技术参数/配置项
- 与其他相关技术的对比

#### 第二部分：场景化讲解

> 从实际问题出发，讲清楚"什么场景用、怎么用、效果如何"

- **问题场景**：实际开发中会遇到什么问题？
- **技术方案**：该技术如何解决这个问题？
- **实现效果**：使用后达到什么效果？（性能指标、数据对比等）
- **最佳实践**：生产环境中的推荐用法和踩坑经验
- **架构图解**：用框图展示该技术在整体架构中的位置

#### 第三部分：模拟面试

> 假设面试场景，进行问答式补充和查漏补缺

- **高频面试题**：列出该主题最常见的面试问题
- **参考答案**：给出结构化的回答思路
- **追问链**：面试官可能的深入追问及应对
- **加分项**：回答中可以提到的亮点（源码细节、生产经验等）
- **易错点**：常见的理解误区和错误回答

### 4. 当前主题列表

- 编程语言与 JVM/Java 生态
- 数据库、缓存与搜索引擎
- 消息队列、流计算与微服务治理
- 运维、云原生与可观测性
- 系统设计、分布式理论与基础计算机知识

### 5. 国家电网计算机类专业课专项

入口：[专业课目录](pages/sgcc-exam.html)，建议先学 [数据结构与算法](pages/sgcc-data-structure.html)。按已核对的2026版大纲专业方向编排，新增7门专项、58个考点单元、74道带解析的自编单选题，以及固定步骤回放与循环队列实操。已有主题页保留，并添加对应专项入口。

专题注明大纲版本、转载来源和核对日期。练习不是官方真题，科目内部未声明官方分值或考频。后续报考年度应以国家电网招聘平台当年公告附件核对范围。

页面均为静态HTML，交互使用 `js/sgcc.js`，样式为 `css/sgcc.css`，无构建依赖。新增题目使用唯一 radio 分组、明确正确答案、独立推导；改动后需检查答题计数、回放边界、队列绕回与移动布局。

交互回归验证：环境需能加载 Playwright 并已安装 Edge，运行 `node tests/sgcc-smoke.cjs`；浏览器可用 `BROWSER_CHANNEL` 指定。验证覆盖74道题的判题/重做、固定回放、队列满空/绕回、链接与四档视口。

### 6. 使用方法

直接在浏览器中打开 `index.html` 即可开始复习。

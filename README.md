# 面试知识复习库 (Interview Prep)

## 项目概述

这是一个用于求职面试准备的知识复习库，以HTML网页形式组织和保存各类技术知识点。

## 项目规范

### 1. 文件结构

```
interview-prep/
├── index.html          # 主菜单页/目录
├── css/
│   └── style.css       # 全局样式表
├── *.html              # 各主题子页面
└── README.md           # 项目说明
```

### 2. 内容规范

- **格式**：所有知识点必须以HTML网页形式保存
- **导航**：每个子页面必须包含返回主菜单的链接
- **结构**：每个主题一个独立HTML文件
- **命名**：文件名使用英文小写 + 连字符（如 `redis.html`, `mysql-index.html`）
- **可视化**：每个页面需包含框图/架构图/流程图等HTML图解，辅助理解

### 3. 每个主题页面的内容结构（必须遵循）

每个知识点/子页面的内容编写必须按照以下三段式结构组织：

#### 第一部分：技术原理

> 从底层原理出发，讲清楚"它是什么、怎么工作的"

- 核心概念定义
- 底层数据结构与实现原理（配框图/架构图）
- 关键机制的运作流程（配流程图）
- 重要的技术参数/配置项
- 与其他相关技术的对比

#### 第二部分：场景化讲解

> 从实际问题出发，讲清楚"什么场景用、怎么用、效果如何"

- **问题场景**：实际开发中会遇到什么问题？
- **技术方案**：该技术如何解决这个问题？
- **实现效果**：使用后达到什么效果？（性能指标、数据对比等）
- **最佳实践**：生产环境中的推荐用法和踩坑经验
- **架构图解**：用框图展示该技术在整体架构中的位置

#### 第三部分：模拟面试

> 假设面试场景，进行问答式补充和查漏补缺

- **高频面试题**：列出该主题最常见的面试问题
- **参考答案**：给出结构化的回答思路
- **追问链**：面试官可能的深入追问及应对
- **加分项**：回答中可以提到的亮点（源码细节、生产经验等）
- **易错点**：常见的理解误区和错误回答

### 6. 全站面试与笔试训练（2026-10-16）

所有67个主题/专项页面增加可播放的状态动画：59个原主题页各补充机制与边界、面试追问及2道自编单选，8个国网专项/目录页补充对应状态动画。首页仍保留原分类和国网专项入口。

- 动画支持播放/暂停、速度选择、前后步进、进度拖动和重置；离开可见页面时暂停；减少动态效果设置会禁用节点闪动。
- 原主题页新增练习支持选择、检查、解析和重做；国网专项原有74题继续保留。
- 内容与固定情景动画数据直接保存在HTML中，公共交互为 `js/study-lab.js`，样式为 `css/study-lab.css`，不依赖网络或构建。
- 每个动画的 `nodes` 定义2–5个角色，`frames` 至少4步；`active` 为当前活动节点下标，`state` 与节点一一对应。这是教学情景回放，不能替代真实系统压测或生产观测。
- 新增自编题使用 `.study-question`、0起始 `data-answer`、四项 `ol` 和带推导的 `details`；关闭JavaScript仍能阅读原始选项和答案。

验证命令：`node tests/study-lab-smoke.cjs`（需Playwright与已安装的Edge，或通过 `BROWSER_CHANNEL` 指定浏览器）。检查所有页面的数据、播放暂停、回退、拖动、重置、判题和手机布局；`STUDY_PAGE_FILTER` 可筛选文件名。国网题库回归仍使用 `node tests/sgcc-smoke.cjs`。

### 7. 全站代码语法高亮

所有 `pre` 与 `div.code` 代码块统一使用本地 vendored highlight.js 11.12.0（BSD-3-Clause，许可证与来源见 `js/vendor/highlight/`）。不请求外部CDN，直接打开HTML也可使用。

`js/code-highlight.js` 根据显式 `language-*` / `data-language`、片段语法和受限语言识别选择语法，并补充中文伪代码；`css/code-highlight.css` 区分关键字、注释、字符串、数值、类型与函数颜色。新增或更新的动态代码块自动处理，保留原文字与缩进。需要准确指定语言时可直接在 code 上添加例如 `class="language-java"`。

验证：`node tests/code-highlight-smoke.cjs`，检查68个页面的代码块覆盖、文本一致、多色、动态更新及移动布局，运行环境与其他Playwright检查一致。

### 9. 全站公式排版

公式使用原生MathML，统一由 `css/math.css`（全局样式自动引入）控制。分数、幂、下标、对数和求和直接存入HTML，支持离线及关闭JavaScript阅读，无外部字体或公式渲染脚本。独立长公式在自身容器内横向滚动，正文和代码使用各自的排版。

数学表达式以 `.math-inline` 或 `.math-block` 的 `span` 包裹；`data-tex` 保存编辑源，`aria-label` 保存可读的线性表达，内部为生成好的MathML。新增或修改公式后，安装仅供编辑使用的依赖 `python -m pip install -r tools/requirements-math.txt`，运行 `python tools/render-math.py` 更新HTML。网站运行不需要Python或该依赖。程序代码、位运算和正则表达式保留原写法；不要用公式转换处理代码块。

验证：`node tests/math-smoke.cjs` 检查全站公式的原生结构、分式布局、离线及无脚本阅读、三档宽度和题目选项格式。共享题目与步骤回放保留HTML节点，避免公式在交互中降为纯文本；相应回归仍运行 `tests/study-lab-smoke.cjs`、`tests/sgcc-smoke.cjs` 与 `tests/bank-exam-smoke.cjs`。
